# Izumo

A bilingual English/Japanese static landing page for getizumo.com.

No build step or package installation is required. Serve the repository root with any static web server.

To publish using GitHub Pages, select main and /(root) in Settings → Pages, then configure getizumo.com as the custom domain before updating DNS at Porkbun.

Contact: hello@izumo.com (as supplied; mailbox domain differs from getizumo.com).

The hero still life is AI-generated editorial imagery, not a catalog of products for sale.
